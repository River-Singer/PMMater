# pmmaster 单项目管理 Skill

首选飞书内部智能体 + 多维表格；通用智能体使用离线 Excel。成员维护本人任务，PM 统筹计划、风险和决定。一套表管理一个项目，正式项目工作与运维/零星优化分别记录。

日常通过智能体对话维护数据，离线使用 Excel；汇报以飞书文档和独立 HTML 交付。HTML 可直接双击打开，保留页签、WBS 展开和 WK 时间范围切换，无需启动本地网页服务。

## 开发环境

需要 Python 3.11+。在本目录安装 requirements.txt，运行：

```text
python -m pip install -r requirements.txt
python -m unittest discover -s tests -q
python -m pm_core.cli --help
```

通用智能体安装时将整个目录放入技能目录并命名为 `pmmaster`，保留 pm_core、references、data 和 requirements.txt。飞书内部宿主按实际产品入口配置指令、知识、工具和触发；本包不声称标准 SKILL.md 可直接一键导入 Aily。

## 已提供的执行路径

- 独立项目 WBS / 运维表、统一校验、Excel 导入导出与迁移备份。
- 项目周期日历、年度来源与公司例外；非员工半日工作安排、未来休假和周容量。
- 周计划承诺、中间成果、延期补救审议 HTML、月度/阶段管理读数。
- 日期变更前后比较、PM 私信核对和周五审计冻结；无历史明确未知。
- 妙记行动预览/执行、来源留痕、冲突检查、防重、删除引用检查和会议邀请失败续做。
- 可选 HTTP 连接器：多维表格、妙记、日历/邀请、真实群 mention、飞书文档。

真实租户权限、工具绑定和触发尚需部署验证。默认配置不发送消息；完成项目授权配置后可按规则持续执行。数据更新应通过统一校验，报告显示同一快照的截止时间；模板的派生值需要重新导出刷新。

仓库内旧导出说明是历史版本来源，不是当前部署状态。不要直接使用其中旧母版 token、固定表 ID 或假定曾经的补号自动化仍存在。
