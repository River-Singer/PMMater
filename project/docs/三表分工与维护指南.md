# 三类核心维护分工

旧版“所有工作统一进入 WBS”已被独立运维设计取代。这里的三类是使用入口，不意味着底层只有三张表。

1. **项目交付**：项目概况、WBS、交付物验收和周承诺。负责人维护执行事实，PM 管结构与计划，有权人员确认基线及验收。
2. **运维与优化事项**：零星配置修改、维护、小优化独立登记/跟踪/关闭。正式纳入项目时保留决定和目标关联，源事项停止重复跟进；不能把运维完成量加进项目进度。
3. **协同与资源**：通讯录、每日工作安排、未来休假、周资源、会议、风险/问题/决定、接口与文档。共享稳定人员/会议身份，关联记录须明确所属表。

成员更新本人任务及安排，PM 处理例外。自动计算/系统字段不手填；状态机与枚举定义来自 [字段字典](字段字典.md)，修改表结构需同步映射/校验/模板，不能只改某个下拉标签。业务编号机制按当前副本明确配置，不假定旧母版补号程序随本包分发。

飞书原生工具与可选桥接遵循 [接入规则](../references/feishu-setup.md)。普通已授权催办与回填自动执行，重要变更依据对应决定；不再要求每一批正常读取或提醒逐次批准。
