# 项目使用文档

从这里查找当前实现的操作方法。此目录随字段、流程和命令一起维护；旧导出说明只作历史来源。

当前入口是智能体对话、离线 Excel 和独立 HTML 报告。HTML 下载后可直接双击打开，无需启动本地网页服务。

| 接入飞书智能体、工具和定时触发 | [飞书母版与智能体驱动](飞书母版与智能体驱动.md)、[具体接入配置](../references/feishu-setup.md) |
| 核对新版母版、公式编号与通讯录变化 | [飞书母版变更同步记录](飞书母版变更同步记录.md) |
| 周一计划、周五结果、每日安排怎么填 | [字段填写说明](字段填写说明.md)、[字段字典](字段字典.md) |
| 每工作日10点查资料、本人反馈、子任务及资源对全局的影响 | [每日任务巡检与资源影响](每日任务巡检与资源影响.md) |

[空白项目模板](../项目管理模板.xlsx)可用于新项目；[项目汇报 HTML](../demo/本周项目汇报.html)、[虚构持续跟进 HTML](../demo/持续跟进与延期审议.html)、[月度资源 HTML](../demo/月度管理复核.html)、[日期变更 HTML](../demo/日期变更审议.html)用于查看效果。

字段字典和 Excel 模板描述本包的统一数据模型，飞书母版按实际字段映射接入。例如本地仍保留稳定 `id` 和可选 `feishu_url`，不表示需要在飞书通讯录恢复已删除的「编号」「飞书通讯地址」。展示首列、公式值与系统记录身份的区别见 [同步记录](飞书母版变更同步记录.md)。

已经提供本地业务校验、报告、连接器和执行台账。真实飞书仍需配置本项目副本字段、应用权限、稳定成员身份、私信/群/日历范围、凭据、持久存储及宿主触发，并完成实际联调。标准 SKILL.md 不是经验证的 Aily 一键部署包；默认配置不会发消息。
