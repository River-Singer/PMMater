# 飞书母版与智能体驱动

当前版本以 [飞书接入与可选 HTTP 桥接](../references/feishu-setup.md) 为唯一接入流程。旧导出说明中的母版 token、table_id、补号脚本和自动化 ID 是历史实例，不能作为新项目默认配置或已上线证明。

每个项目建立独立副本，发现实际表/字段并映射；项目 WBS 和运维与优化事项是两张独立表。成员维护本人事实，PM 管计划/风险/决定；权限在真实租户按此分工配置，不能沿用“只有所有者可写”的旧演示权限。

## 母版当前规则

依据用户提供的 2026-11-11 变更备份，终态已同步为以下规则。详细公式、差异及核验步骤见 [母版变更同步记录](飞书母版变更同步记录.md)。这是本地 Skill 和接入约定的同步，未在此执行真实飞书变更。

| 表 | 成员看到的首列 | 智能体维护方式 |
|---|---|---|
| 通讯录 | 姓名 | 不再维护旧编号和飞书通讯地址；邮箱或姓名+部门用于查找消歧，保留真实 record_id 和已核实通知身份 |
| WBS总表 | WBS编号，公式生成 | 新增只写业务字段，保存后回读编号；保留父级WBS／抽屉关联；不手写、不补跳号 |
| 项目概况 | 编号，公式取英文缩写 | 英文缩写是显示编号及 WBS 前缀的维护入口；不得删除/改名该字段，变更值需评估影响 |

公式依赖的 WBS「流水号」「创建时间」同样不能删除或改名。首列显示值不等于永久记录身份；项目关联或英文缩写变化时，不能让任务关联、会议行动和日期留痕断开。离线 Excel 继续保留自己的稳定编号，不按飞书列数机械删除本地字段。

状态类下拉保持固定；其他下拉选项调整先写入「下拉选项修改日志」，记录表/字段、变更前后、原因、依据、操作者及时间，再同步智能体映射和校验。未找到日志表或无写权限时，先列待处理，不直接改选项。

## 接入与执行

连接配置包含项目、有效期、时区、日历、身份映射、通知群/成员范围、例会与收集时刻、字段读写和决定人。设置完成后范围内催办/预约/事实回填按规则持续执行，不要求每次重新批准。重要变更与明确删除仍须具名决定依据。

原生宿主工具与包内 HTTP 桥接是两条可选执行路径，复用 [会议行动契约](../references/meeting-actions.md)。宿主承担调度与凭据续期，执行台账必须持久保存。API 公开存在不等于应用已获权限，标准 SKILL.md 不等于已验证的 Aily 一键安装格式。

HTML 与飞书文档使用同一读取快照；本地 HTML 文件不是已发布网络链接。飞书正式接入前检查完整分页、字段类型、关联表、真实 @、日历组织身份、邀请部分失败和重复事件恢复。

## 直接编辑的日期留痕

宿主应保存审计事件或连续观察；包内 agent-tick 的 --ledger 同时保存日期快照与成功读取检查点。配置已核实的 PM 私聊 pm_private_chat_id 与对应 pm_private_recipient_id，缺渠道只输出待配置，不向项目群发送日期疑点。具体政策、历史限制与实时捕获规则见 [日期变更审议](日期变更审议与留痕.md)。
