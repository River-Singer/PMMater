# pmmaster 字段字典

本文件由 pm_core/schema.py 自动生成；下拉值、Python校验、SQLite字段与Excel列来自同一份定义。

一个工作区管理一个完整项目。人员只维护项目通讯录；参与关系、结构化依赖和产品服务是内部兼容对象，不要求日常单独填写。ID新增可留空自动生成；关系使用稳定ID，Excel显示为‘ID · 名称’。所有日期为ISO日期，时间必须包含时区。版本号用于旧文件冲突检查。

## 工作项状态迁移

- `intake` → cancelled, ready
- `ready` → blocked, cancelled, in_progress, intake
- `in_progress` → blocked, cancelled, in_review
- `blocked` → cancelled, in_progress, ready
- `in_review` → cancelled, done, in_progress
- `done` → in_progress
- `cancelled` → intake

## 优先级口径

建议优先级由影响×紧迫性计算，仅作为建议。人工优先级与建议不同或选择P0时需留理由；这里的P0–P3是本模板可调整的分级，不冒称PMI/四大的统一标准。严重度仅描述Bug/故障自身后果。没有自动承诺响应SLA。

## 系统记录

event_log保留每次事务的实体、编号、变更前后、操作者标签和记录时间。snapshots保留固定报告时点的完整事实快照；数据库文件可备份。操作者标签不是身份认证，Excel隐藏/锁定也不是权限安全边界。
