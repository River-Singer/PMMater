# 演示资料说明

本目录所有人员、工作、会议、链接和人员账号均为虚构示例，不用于向真实成员发送消息。

下载后直接双击 [本周项目汇报](本周项目汇报.html)、[持续跟进与延期审议](持续跟进与延期审议.html) 或 [月度管理复核](月度管理复核.html) 查看。HTML 自带页签、WBS 展开和范围切换，无需启动本地网页服务。Excel 示例保留在 `演示工作台.xlsx`，该名称指工作簿，不是网页应用。

包根目录的 `run_demo.bat` 是可选离线生成入口，输出到 `demo_run/`，不启动网页服务。本目录保留经过核对的固定快照，重新生成的虚构材料应与它区分。

当前数据样例为字段模型 v7，固定演示截止时点是 **2026-11-11 17:00（Asia/Shanghai）**：

- `demo.sqlite3`、`demo_facts.json` 和 `演示工作台.xlsx` 来自同一份已校验数据。
- 包含独立运维事项、延期原因与补救措施、待审议决定、每日工作安排、未来半日休假、周资源安排及跨周任务的本周成果承诺。
- Excel 的只读统计是导出时点快照；导入更改后应重新导出。
- 生成或核对当前 HTML 报告时，使用 `demo_facts.json` 和相同截止时点，不重新从另一份演示数据推断已确认事实。
- 修改报告渲染代码后，在包根目录运行 `python -m pm_core.demo_reports` 重建本目录的当前 HTML（只改写内容有变化的文件）；`--check` 只核对，测试 `tests/test_demo_reports.py` 会在演示与代码不一致时失败。版式与配色约定见 [HTML 报告制作说明](../docs/HTML报告制作说明.md)。

`weekly_reports/` 内以 `2026-11-02_` 开头的文件是原包保留的历史周报样例，使用旧模型 v6 的当时快照。它们不是当前 v7 工作簿的计算结果，也没有被回填成后来才知道的事实；其历史报告编号不用于定位重建后演示库中的当前记录。

空白正式项目请从包根目录的 `项目管理模板.xlsx` 或初始化命令开始。项目日期、提醒时区、年度日历、人员身份和真实飞书连接应按实际项目配置。

日期变更的独立虚构案例见 [日期变更审议](日期变更审议.html)，其 [观察来源](日期观测来源.json)保留前后两份事实。该案例不表示主示例库或真实成员发生过改期。
